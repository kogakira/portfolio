# evielynn.dev

Personal portfolio site. One static `index.html`, no build step.

Hosted on GitHub Pages, domain and DNS on Cloudflare.

## Editing

Edit `index.html`, commit, and push to `main`. GitHub Pages redeploys on its own.

## Files

- `index.html` — the whole site
- `CNAME` — custom domain for GitHub Pages
- `.nojekyll` — serve files as-is, skip Jekyll
